Add browser-based plan approval, annotation, and code review to Pi using
`pi install npm:@plannotator/pi-extension`.

Upstream instructions: https://github.com/backnotprop/plannotator/blob/main/apps/pi-extension/README.md

The Pi extension does not require the standalone Plannotator installer.
